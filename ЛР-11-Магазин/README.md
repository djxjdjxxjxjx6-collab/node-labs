## Как запустить

```bash
python3 -m http.server 8080
```
и откройте http://localhost:8080

## Проверка работы

1. «Зарегистрироваться» → имя (необязательно), email, пароль от 6 символов —
   сразу появится кабинет покупателя, в шапке «Привет, [Имя]!».
2. Обновите страницу (F5) — вы остаётесь авторизованы.
3. В кабинете измените имя — шапка и кабинет обновятся сразу.
4. «Выйти», затем войдите под другим покупателем — кабинет обновится.
5. Firestore Console → коллекция `users` → документ с полями
   `email`, `displayName`, `createdAt`, `role: "customer"` — скриншот в отчёт.
