## ✨ Версия 2.0 — полноценный мини-магазин TechShop

**Дизайн:** современный интерфейс (шрифт Inter, карточки, градиенты, анимации), светлая и тёмная тема,
адаптивная вёрстка под телефон, скелетоны при загрузке, всплывающие уведомления.

**Для покупателя:**
- поиск по каталогу, фильтр по категориям, «только в наличии», сортировка (цена, название, наличие, новизна);
- избранное ❤️, корзина с выдвижной панелью и счётчиком, проверка остатков;
- оформление заказа → коллекция `orders`; раздел «Мои заказы» со статусами, отмена нового заказа;

**Для администратора (`role: "admin"`):**
- статистика: товары, единицы на складе, стоимость склада, выручка;
- таблица товаров: цена меняется прямо в таблице, остаток кнопками −/+, редактирование и удаление;
- добавление товара с категорией, иконкой-эмодзи и описанием;
- заказы: фильтр по статусу, цепочка «Новый → Подтверждён → Отправлен → Доставлен» или «Отменён».
  При подтверждении остатки списываются **транзакцией** (`runTransaction`) — нельзя продать больше, чем есть.

**Безопасность (firestore.rules):** добавлена коллекция `orders` — покупатель создаёт только свои заказы
со статусом `new` и видит только свои; отменить может только свой новый заказ; менять статусы и видеть все
заказы может только admin; удалять заказы нельзя никому. Для товаров проверяются описание и эмодзи.

## Как запустить

```bash
python3 -m http.server 8080
```
и откройте http://localhost:8080

## Как сделать администратора

1. Зарегистрируйтесь через интерфейс — пользователь получит роль `customer`.
2. Firestore Console → `users` → документ пользователя → поле `role` → `admin` → Update.
3. Обновлять страницу не нужно: профиль читается через `onSnapshot`, форма появится сама.

## Проверка работы

- Гость и `customer`: только каталог, без формы и кнопок управления.
- `admin`: форма «Добавить товар», у каждого товара кнопки **−1 / +1** (остаток на складе) и **Удалить**.
- Добавьте / удалите товар, измените остаток — список обновится сам (onSnapshot), в том числе в других вкладках.
  Когда остаток станет 0 — статус сменится на «❌ Нет в наличии».
- Под `customer` попробуйте записать в `products` из консоли браузера — правила вернут `permission-denied`.

**Вывод:** реализовано разграничение прав по ролям. Роль хранится в профиле `users/{uid}`
и проверяется дважды: в интерфейсе (показ формы и кнопок) и в правилах Firestore
(`isAdmin()` через `get()`), поэтому обойти ограничение из консоли браузера нельзя.
Каталог обновляется в реальном времени через `onSnapshot`, остаток меняется атомарно
через `FieldValue.increment`.
