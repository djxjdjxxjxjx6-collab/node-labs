## Как это настраивалось (для отчёта)

1. Создан проект **shop-sy** (shop-ваши-инициалы; ID `shop-sy-71ed8`)
2. Build → Firestore Database → «Создать базу». Сразу после создания опубликованы правила тестового режима
   (`allow read, write: if request.time < ...`), позже их заменили постоянные правила из ЛР-12.
3. Project settings → Your apps → «Add app» → Web → **MyShop**; `firebaseConfig` вставлен в `index.html`.
4. В Firestore создана коллекция **products** с 3 документами:

| name | category | price | quantity |
|---|---|---|---|
| Беспроводная мышь | Периферия | 4990 | 15 |
| Механическая клавиатура | Периферия | 18990 | 0 |
| Наушники с микрофоном | Аудио | 12490 | 7 |

(поля `price` и `quantity` — тип **number**, `name` и `category` — **string**)

## Как запустить

```bash
python3 -m http.server 8080
```

Откройте http://localhost:8080 — каталог загрузится из Firestore.
